# Kids YouTube — סרטונים לילדים

Kids YouTube הוא פרויקט משפחתי לילדים עם רשימת תוכן מאושרת בלבד.

## המצב הנוכחי

- **אפליקציית Android** היא המקום שבו הסרטונים מתנגנים בפועל.
- **האתר** מציג סרטונים, ערוצים, תמונות וכותרות, אבל אינו מנגן סרטונים בדפדפן.
- לחיצה על סרטון באתר מציגה הודעה שהסרטון מיועד לאפליקציית Kids YouTube ומנסה לפתוח אותה ב־Deep Link.
- **אזור ההורים** נמצא ב־[parents.html](https://yt2178.github.io/kids-youtube/parents.html) ומשתמש בסיסמה משפחתית ובשמירה ישירה דרך שירות Supabase.
- ההורה אינו צריך לדעת ש־GitHub קיים ואינו צריך לבצע אישור ידני ב־GitHub.

## אפליקציית הילדים

האפליקציה מציגה רק תוכן שהגיע מרשימת האישורים של ההורה. היא כוללת:

- סרטונים מאושרים, ערוצים מאושרים ואיחוד של שניהם.
- חיפוש מקומי בתוך התוכן המאושר בלבד.
- תצוגת כרטיסים או רשימה; הבחירה נשמרת במכשיר.
- UI מותאם לטלפונים קטנים, טלפונים גדולים, טאבלטים, Portrait ו־Landscape.
- מצבי טעינה, רשימה ריקה ושגיאה נפרדים.
- נגן Media3 מקומי ב־Android.
- fallback בין מקורות מדיה מוגבלים.
- בדיקת הרשאה מחדש לפני ניגון תוכן שמגיע מערוץ.

## אזור ההורים

הזרימה היא:

1. כניסה עם סיסמה.
2. אפשרות **זכור אותי במכשיר הזה**.
3. הדבקת קישור YouTube של סרטון או ערוץ.
4. בדיקת הקישור והתוכן.
5. הוספה או ביטול אישור.
6. שמירה ישירה לשירות המשפחתי.

אין GitHub Issues, אין Commit ידני ואין צורך בחשבון GitHub. הוראות מלאות: [PARENTS.md](./PARENTS.md).

## מקור האישורים

מקור האמת המקוון הוא שירות Kids YouTube ב־Supabase. הקובץ videos.txt נשמר כ־fallback מקומי/תאימות בלבד ואינו מסלול העריכה של ההורה.

האפליקציה מגבילה קישורי YouTube לצורות הנתמכות ומבצעת בדיקות נוספות בצד Android לפני ניגון. כתובות מדיה מורשות רק ב־HTTPS מול googlevideo.com ותתי־הדומיין שלו; redirects במדיה נבדקים לפני כל חיבור ליעד הבא.

## האתר

האתר הוא תצוגה וניהול בלבד. הוא אינו מכיל נגן וידאו פעיל. הסרטונים מוצגים עם thumbnail, כותרת ופרטי ערוץ, ולחיצה מפנה לאפליקציה.

GitHub Pages משמש לפרסום הקבצים הסטטיים. הוא אינו מנגנון האישור של ההורה.

## Android Studio

פתחו את תיקיית **android** מתוך הריפו ב־Android Studio. הפרויקט כולל Gradle wrapper.

דרישות עיקריות:
- Android 6 ומעלה.
- Android System WebView מעודכן.
- חיבור אינטרנט לטעינת תוכן ולניגון.

## בדיקות

בדיקות JavaScript:

    node --test tests/*.test.cjs

בדיקות Android וה־APK נבנים ב־GitHub Actions בכל שינוי רלוונטי וב־Pull Requests לפני מיזוג ל־main.

הבדיקות כוללות parsing ואבטחת קישורים, חיפוש, Grid/List, מצבי empty/error/loading, bridge של Android, CSP/CORS מול Supabase, Deep Link, מדיניות מדיה ו־redirects, ו־build מלא של אפליקציית הילדים.

בדיקה פיזית של הנגן נדרשת בנוסף לבדיקות האוטומטיות. תיקון HTTP 302 של Media3 נבדק בפועל, והמשתמש דיווח שכל הסרטונים נפתחו לאחר התיקון.

## QA תצוגה

qa/mobile.html מאפשר לבדוק את האתר ברוחבים וגבהים שונים, כולל 320/360/390/412, טאבלטים ו־Landscape קצר.

## פרטיות ואבטחה

- ילדים אינם יכולים להזין URL מתוך אפליקציית הילדים.
- אין token של GitHub בדפדפן.
- סשן ההורה נשמר במכשיר רק לצורך זכירת הכניסה.
- השירות מאמת את פעולות ההורה בצד השרת.
- קישורים חיצוניים שרירותיים אינם מורשים באפליקציית הילדים.
