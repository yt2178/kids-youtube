# שירות ניגון — ניסוי מבודד

האתר הראשי נשאר כפי שהיה. הענף הזה אינו מחובר לאתר הילדים ולא נחשב עדיין לפתרון ניגון מוכח.

השירות משתמש ב־Node 24 וב־youtubei.js 18.1.0, עם QuickJS מבודד ב־WebAssembly לפענוח קוד הנגן. אין חשבונות Google, cookies, מפתחות API, מסד נתונים, שרת ביתי או החלפת כתובות כדי לעקוף חסימות.

## אישורים ואבטחה

- מקור האישורים הקבוע הוא videos.txt בענף main של המאגר.
- קישורים מזוהים כסרטון, ערוץ UC או כינוי של ערוץ. ההערות מתחילות ב־//.
- לפני ניגון מאומת אישור ישיר או זהות ערוץ מאושר.
- האישורים מתרעננים לכל היותר כל 30 שניות; כשל בטענת רשימה מעודכנת סוגר את ההרשאה בצד השרת.
- אין proxy לכתובת שמוסר המשתמש. רק מקור Googlevideo שנבחר מהמידע של הסרטון המאושר, ללא redirects.
- CORS מוגבל ל־https://yt2178.github.io. הגבלת origin אינה תחליף לאימות הרשאות.
- טווח מדיה יחיד עד 4 MiB, שני זרמים במקביל והגבלת תעבורה של 64 MiB ליממה לתהליך הניסוי.
- מגבלת הניסוי אינה הבטחת חיוב: היא מתאפסת עם הפעלה מחדש, ומכסות הענן משותפות לשירותים אחרים.
- דרישת אימות/התחברות בנגן עוצרת את המקור ל־15 דקות. כשל HTTP רגיל נשמר למשאב שנכשל ל־60 שניות (429: שתי דקות), בלי לחסום סרטון ידני בגלל כשל בזיהוי ערוץ. אין ניסיון לפתור CAPTCHA או לעבור בין לקוחות כדי לעקוף חסימה.

## בדיקה

npm install --prefix backend --ignore-scripts
npm test --prefix backend
node backend/live-probe.mjs

בדיקת הניגון קוראת את רשימת האישורים האמיתית, בוחרת סרטון ידני, מאמתת metadata ו־CORS, מקבלת טווח MP4 ומפענחת שלוש תמונות בעזרת ffmpeg. כשל אמיתי נכשל בבדיקה — דף שגיאה או הצלחת metadata אינם נחשבים לניגון.

האימות עדיין דורש בדיקת דפדפן אמיתית אחרי הצלחת פענוח. בדיקת ffmpeg אינה בדיקת autoplay או טאבלט.

## הקמה חינמית אחרי הוכחת ניגון

Web Service חדש ב־Render: runtime Node, plan Free, branch playback-cloud-proof.
Build: npm install --prefix backend --ignore-scripts --no-audit --no-fund
Start: node backend/server.mjs
PORT מגיע מ־Render. אין build לאתר הסטטי.

חשוב: Free נרדם אחרי 15 דקות; התעוררות יכולה לקחת כדקה. מכסות שעות ותעבורה משותפות לכל שירותי המרחב. אין צורך בכרטיס אשראי לניסוי, ואין לעבור למסלול בתשלום. לא מפעילים ping כדי להשאיר שירות ער.

## תוצאת הבדיקה החיה ב־2026-10-06

ריצה: https://github.com/yt2178/kids-youtube/actions/runs/37430365068

122 בדיקות אתר ו־17 בדיקות שירות עברו. הבדיקה החיה עבור mVTlbvQ_010 נכשלה: האישורים נטענו (200, 152ms); בקשת הסרטון חזרה עם UPSTREAM_BLOCKED (503, 890ms) בעקבות דרישת אימות/התחברות בנגן. לא התקבלו bytes של מדיה ולא פוענח וידאו.

לא חיברנו את הניסוי לאתר ולא יצרנו שירות Render. אין אישור לניגון עובד ואין שינוי בממשק הילדים או בקישורים המאושרים. בדיקות push לא חוזרות לפנות למקור החסום; בדיקה חיה נוספת דורשת הפעלה ידנית לאחר שינוי במצב המקור. אין לעקוף את דרישת האימות.

בדיקות דפדפן Desktop/Android, Console ו-Network לא בוצעו מחדש בשלב הניסוי: סביבת ההרצה המקומית מנותקת. בדיקות HTTP אמיתיות מקומיות ב-CI בדקו CORS, טווחי מדיה, ביטול אישורים ומגבלות שירות; המדיה בהן מדומה ואינה הוכחת ניגון YouTube.
